# Vaadin-SAE

## Convention de commits
Pour un ajout (feature) : 
>feat | #id-card | description commit
>
Pour correction d'un bug : 
>fix | #id-card | description commit
>
Exemple d'un commit feature :
>feat #0 ajout d'un bouton sur la page livres
>
Exemple d'un commit fix :
>fix #5 correction du tableau des utilisateurs ne s'affiche pas
>
## Tableau Kamban
Le tableau kamban permet de visualiser l'avancement des tâches.
